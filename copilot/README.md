# GitHub Copilot CLI + Shield KYA

Auto-wire: `kya connect copilot` (global `~/.copilot/mcp-config.json`).

Manual: merge `mcp-config.example.json` into your mcp-config.json, or use the interactive `/mcp add` form with the same command/args.

Verify with `/mcp show` inside Copilot CLI — shield-kya should be listed with three tools.

Full recipe: [docs/hosts/copilot.md](../docs/hosts/copilot.md)
