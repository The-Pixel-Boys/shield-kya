# Scoop packaging for Shield KYA

This is a local copy of the manifest that lives in
`The-Pixel-Boys/scoop-bucket`. The canonical source is at
<https://github.com/The-Pixel-Boys/scoop-bucket/blob/main/bucket/shield-kya.json>.

## Install

```powershell
scoop bucket add The-Pixel-Boys https://github.com/The-Pixel-Boys/scoop-bucket.git
scoop install shield-kya
```
