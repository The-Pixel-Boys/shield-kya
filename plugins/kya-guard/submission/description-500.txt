Stops your coding agent from deleting, leaking or dropping things. No network, one file, fails open. KYA Guard checks every tool call before it runs. It stops destructive commands (terraform destroy, DROP TABLE, git push --force, rm -rf ~), reads of credential files, secrets written into files and secrets sent over the network. A few risky commands ask you first. The check is local and offline. If the guard fails, the call goes ahead and one error line is written. Needs Node.js 22 or later.
